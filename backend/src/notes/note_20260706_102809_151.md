4. **单菜详细做法**

### 菜名：豆腐炒鸭血

#### 食材明细
- 豆腐 1块  
- 鸭血 250ml  
- 莴笋 1根  
- 黄瓜 1根  
- 姜 6片  
- 蒜仔 6瓣  
- 香葱 2根  
- 辣椒 1000g（根据个人吃辣喜好程度可选青椒、线椒、美人椒等，喜欢吃辣可增加5-8个小米辣或朝天椒）  
- 酒（任选其一）：高度白酒50ml + 水150ml / 啤酒200ml / 米酒200ml  
- 生抽 10ml  
- 料酒 30ml  
- 盐 8g  
- 鸡精 5g  

#### 分步烹饪步骤
1. 准备食材：将豆腐切块，鸭血切片，莴笋和黄瓜切片，姜切片，蒜仔切末，香葱切段。
2. 热锅凉油，放入姜片和蒜末爆香。
3. 加入鸭血翻炒至变色。
4. 放入豆腐块，继续翻炒均匀。
5. 加入莴笋和黄瓜片，快速翻炒。
6. 根据口味加入辣椒、生抽、料酒、盐和鸡精调味。
7. 最后撒上香葱段，翻炒均匀即可出锅。

#### 烹饪小贴士
- 鸭血在炒制前可以先焯水，去除腥味。
- 若喜欢更清淡的口感，可减少辣椒的使用量。

### 菜名：土豆炖黄瓜

#### 食材明细
- 土豆 240g  
- 黄瓜 100克 * 份数  
- 猪肉 50克 * 份数  
- 油量 50克 * 份数  
- 盐量 10克 * 份数  
- 酱油 5克 * 份数  
- 蒜瓣 2瓣 * 份数  
- 小米辣 1根 * 份数  
- 大蒜 4瓣  
- 青椒 0.5个  
- 红椒 0.5个  
- 干辣椒 3个  
- 葱 1根  
- 生抽 5ml  
- 陈醋 10ml  
- 盐 2g  
- 食用油 10-15ml  

#### 分步烹饪步骤
1. 准备食材：将土豆去皮切块，黄瓜切片，猪肉切片，蒜瓣切末，葱切段，青椒和红椒切丝，干辣椒剪段。
2. 热锅凉油，放入蒜末和干辣椒爆香。
3. 加入猪肉片翻炒至变色。
4. 放入土豆块，翻炒均匀。
5. 加入黄瓜片、青椒和红椒丝，继续翻炒。
6. 根据口味加入酱油、盐、陈醋、生抽和小米辣调味。
7. 最后撒上葱段，翻炒均匀即可出锅。

#### 烹饪小贴士
- 土豆炖煮时间不宜过长，以免过于软烂。
- 可根据个人口味调整辣椒的用量。

5. **厨房操作先后建议**
- 先处理蔬菜类食材：将豆腐、鸭血、莴笋、黄瓜、土豆等清洗干净并切好。
- 热锅凉油，先炒鸭血和豆腐，再加入莴笋和黄瓜。
- 同时准备土豆炖黄瓜的食材，热锅后先炒猪肉，再加入土豆和黄瓜。
- 最后根据口味进行调味，确保两道菜同时完成。

6. **整体营养小结**
- 总热量：约550大卡（豆腐炒鸭血 300大卡 + 土豆炖黄瓜 250大卡）

- 微调建议：若用户对辣味敏感，可适当减少辣椒的使用量；若希望增加蛋白质摄入，可考虑添加更多肉类。

7. **饮食安全提醒**

4. **单菜详细做法**
### 番茄炒土豆
**食材明细**
- 番茄 1个
- 土豆 1个
- 盐 少许
- 食用油 适量

**分步烹饪步骤**
1. 番茄洗净切块，土豆去皮切片。
2. 热锅倒油，放入土豆片翻炒至微黄。
3. 加入番茄块继续翻炒，加入少许盐调味。
4. 炒至番茄出汁，土豆软熟即可出锅。

**烹饪小贴士**
- 土豆切片后可浸泡在水中防止氧化变色。
- 番茄炒制时间不宜过长，以免失去口感。

### 土豆番茄汤
**食材明细**
- 番茄 1个
- 土豆 1个
- 清水 500ml
- 盐 少许
- 食用油 适量

**分步烹饪步骤**
1. 番茄洗净切块，土豆去皮切丁。
2. 热锅倒油，放入土豆丁翻炒片刻。
3. 加入清水煮沸，放入番茄块继续煮10分钟。
4. 最后加盐调味，搅拌均匀即可。

**烹饪小贴士**
- 可根据个人口味加入少量胡椒粉提味。
- 番茄和土豆的比例可根据喜好调整。

5. **厨房操作先后建议**
- 先准备食材：将番茄和土豆清洗干净并切好。
- 先做“土豆番茄汤”：因为需要一定时间煮制，先开始煮汤。
- 在汤煮的过程中，可以同时进行“番茄炒土豆”的准备工作。
- 最后完成“番茄炒土豆”，确保两道菜同时上桌。

# 研究报告：低脂不辣，现有食材 黄瓜，鸡蛋，土豆，两菜一汤

<REPORT_TEMPLATE>
1. **用餐需求总览**  
   - 用户原始需求：低脂不辣  
   - 忌口/过敏原：暂无相关信息  
   - 用户冰箱现有食材：黄瓜、鸡蛋、土豆  
   - 整体用餐定位：一人食、快手晚餐  

2. **整套菜单概览表**  
| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|----------------|
| 黄瓜拌鸡蛋   | 10分钟   | 简单 | 约150大卡      |
| 土豆炒青菜   | 15分钟   | 简单 | 约200大卡      |

3. **分类采购清单**  
   - 已有食材（无需额外购买）：黄瓜、鸡蛋、土豆  
   - 需要采购食材：青菜（根据实际选择的蔬菜种类，如小白菜、菠菜等）  

4. **单菜详细做法**  
   ### 黄瓜拌鸡蛋  
   - **食材明细**：  
     - 黄瓜 1根  
     - 鸡蛋 2个  
     - 生抽 1勺  
     - 香油 1小勺  
     - 盐 少许  
   - **分步烹饪步骤**：  
     1. 黄瓜洗净切片，放入碗中。  
     2. 鸡蛋煮熟后剥壳，切成小块，加入黄瓜碗中。  
     3. 加入生抽、香油和盐，搅拌均匀即可。  
   - **烹饪小贴士**：  
     - 可以提前将黄瓜切片并用盐腌制10分钟，去除多余水分，口感更脆。  

   ### 土豆炒青菜  
   - **食材明细**：  
     - 土豆 1个  
     - 青菜（如小白菜、菠菜等）适量  
     - 生抽 1勺  
     - 盐 少许  
     - 食用油 1小勺  
   - **分步烹饪步骤**：  
     1. 土豆去皮切片，青菜洗净备用。  
     2. 热锅加少量食用油，放入土豆片翻炒至微黄。  
     3. 加入青菜，快速翻炒至断生。  
     4. 加入生抽和盐调味，翻炒均匀即可出锅。  
   - **烹饪小贴士**：  
     - 土豆可先焯水1分钟再炒，口感更软嫩。  

5. **厨房操作先后建议**  
   - 先处理黄瓜拌鸡蛋：黄瓜切片、鸡蛋煮熟，准备调料。  
   - 同时开始处理土豆炒青菜：土豆切片、青菜清洗，热锅炒制。  
   - 最后将两道菜装盘，完成整餐。  

6. **整体营养小结**  
   - 总热量：约350大卡  
   - 饮食适配评价：符合低脂不辣的饮食要求，富含蛋白质和膳食纤维，适合健康饮食。  
   - 微调建议：可根据个人口味添加少量蒜末或辣椒油提升风味，但需注意避免辣味。  

7. **饮食安全提醒**  
   - 本套餐完全规避了用户忌口和过敏原（暂无相关信息）。  
   - 所有食材均为用户现有库存或合理采购，确保食品安全。

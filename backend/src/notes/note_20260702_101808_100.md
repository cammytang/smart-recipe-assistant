# 用户需求：低脂不辣，现有食材 番茄 土豆

4. **单菜详细做法**
### 番茄炒土豆
- **食材明细**：
  - 番茄 1个
  - 土豆 1个
  - 盐 适量
  - 食用油 1小勺
- **分步烹饪步骤**：
  1. 土豆去皮切片，番茄洗净切块。
  2. 热锅加少量食用油，放入土豆片翻炒至微黄。
  3. 加入番茄块，继续翻炒至番茄出汁。
  4. 根据口味加入适量盐调味，翻炒均匀即可出锅。
- **烹饪小贴士**：
  - 可根据个人口味加入少许糖提鲜。
  - 若喜欢更软烂口感，可适当延长翻炒时间。

### 土豆沙拉
- **食材明细**：
  - 土豆 1个
  - 番茄 1个
  - 盐 适量
  - 黑胡椒 少许
  - 橄榄油 1小勺
- **分步烹饪步骤**：
  1. 土豆去皮切丁，番茄洗净切丁。
  2. 土豆丁放入沸水中煮熟后捞出，过冷水备用。
  3. 将土豆丁和番茄丁混合，加入盐、黑胡椒和橄榄油拌匀。
  4. 放入冰箱冷藏10分钟后食用更佳。
- **烹饪小贴士**：
  - 可加入少量酸奶或柠檬汁提升风味。
  - 冷藏后口感更清爽，适合夏季食用。

5. **厨房操作先后建议**
   - 先处理土豆：将土豆切片或切丁，提前煮熟或炒制。
   - 同时处理番茄：将番茄切块或切丁，用于炒菜或沙拉。
   - 番茄炒土豆可在炒制过程中完成，而土豆沙拉则需在炒制完成后进行冷拌。
   - 建议先做番茄炒土豆，再制作土豆沙拉，避免食材浪费。

6. **整体营养小结**

   - 微调建议：可根据个人口味添加少量香草或蒜末增加风味，但需注意控制油脂用量。

# 用户需求：两菜一汤，低脂不辣，现有食材 番茄 土豆

# 完整菜谱报告

## 1. **用餐需求总览**
- 用户原始需求：两菜一汤，低脂不辣。
- 忌口/过敏原：暂无相关信息。
- 用户冰箱现有食材：番茄、土豆。
- 整体用餐定位：低脂、清淡、适合一人食或家庭餐。

## 2. **整套菜单概览表**
| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|----------------|
| 番茄炒蛋     | 15分钟   | 简单 | 200大卡        |
| 土豆炖鸡     | 30分钟   | 中等 | 300大卡        |
| 清炒时蔬     | 10分钟   | 简单 | 100大卡        |

## 3. **分类采购清单**
### 已有食材（无需额外购买）
- 番茄
- 土豆

### 需要采购食材（多道菜同名食材自动合并用量，避免重复采购）
- 鸡蛋：1个/人
- 牛肉：150g/人
- 盐：2g/人
- 胡椒粉：0.5g/人

## 4. **单菜详细做法**
### 番茄炒蛋
#### 食材明细
- 番茄：1个/人
- 鸡蛋：1个/人
- 盐：2g/人
- 胡椒粉：0.5g/人

#### 分步烹饪步骤
1. 番茄洗净切块，鸡蛋打散备用。
2. 热锅凉油，放入番茄翻炒至出汁。
3. 加入鸡蛋液，快速翻炒均匀。
4. 根据口味加入盐和胡椒粉调味即可。

#### 烹饪小贴士
- 番茄炒制时间不宜过长，以免失去鲜味。
- 可根据个人口味添加少量糖提鲜。

### 土豆炖鸡
#### 食材明细
- 土豆：1个/人
- 鸡肉：150g/人
- 盐：2g/人
- 胡椒粉：0.5g/人

#### 分步烹饪步骤
1. 土豆去皮切块，鸡肉切块备用。
2. 热锅凉油，将鸡肉煎至表面微黄。
3. 加入土豆块翻炒，加适量水煮沸。
4. 小火慢炖15分钟，至土豆软烂。
5. 根据口味加入盐和胡椒粉调味即可。

#### 烹饪小贴士
- 土豆炖煮前可先焯水，去除多余淀粉。
- 若喜欢更浓郁的口感，可加入少量酱油提味。

### 清炒时蔬
#### 食材明细
- 时蔬（如西兰花、胡萝卜、青豆等）：适量
- 盐：2g/人
- 胡椒粉：0.5g/人

#### 分步烹饪步骤
1. 时蔬洗净，分装备用。
2. 热锅凉油，放入时蔬快炒。
3. 根据口味加入盐和胡椒粉调味。
4. 炒至蔬菜变色即可出锅。

#### 烹饪小贴士
- 时蔬可根据个人喜好选择，尽量选择当季新鲜蔬菜。
- 快炒时保持大火，保留蔬菜的营养和脆嫩口感。

## 5. **厨房操作先后建议**
1. 先处理番茄炒蛋：准备番茄和鸡蛋，快速炒制。
2. 接着制作土豆炖鸡：先煎鸡肉，再炖煮土豆。
3. 最后清炒时蔬：利用剩余时间快速炒制。

## 6. **整体营养小结**
- 总热量：约600大卡/人
- 饮食适配评价：符合低脂、清淡、不辣的需求，营养均衡。
- 微调建议：若需增加蛋白质摄入，可适当增加鸡肉或鸡蛋的用量。

## 7. **饮食安全提醒**
- 本套餐中未使用任何忌口或过敏原食材。
- 所有菜品均采用清淡少油的做法，符合低脂饮食要求。

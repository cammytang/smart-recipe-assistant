# 完整菜谱套餐：低脂不辣，现有食材 番茄 土豆

## 4. **单菜详细做法**

### 快手家常炒蛋

#### 食材明细
- 番茄 1个
- 土豆 1个
- 鸡蛋 2个
- 盐 适量
- 食用油 适量

#### 分步烹饪步骤
1. 将番茄洗净切块，土豆去皮切片。
2. 在热锅中加入适量食用油，放入番茄翻炒至出汁。
3. 加入土豆片继续翻炒，炒至土豆变软。
4. 打入鸡蛋，快速翻炒均匀，使鸡蛋熟透。
5. 根据口味加入适量盐调味，翻炒均匀后即可出锅。

#### 烹饪小贴士
- 番茄和土豆可以提前准备好，节省时间。
- 炒蛋时火候不宜过大，避免鸡蛋过老。

## 5. **厨房操作先后建议**
1. 准备食材：将番茄和土豆清洗干净并切好。
2. 热锅加油，先炒番茄，再加入土豆。
3. 最后打入鸡蛋，快速翻炒至熟。
4. 调味后即可出锅。

## 6. **整体营养小结**
- **总热量**：约300大卡
- **饮食适配评价**：符合低脂、不辣的饮食需求，适合快手晚餐。
- **微调建议**：可增加一些蔬菜或蛋白质来源以提升营养均衡性。

## 7. **饮食安全提醒**

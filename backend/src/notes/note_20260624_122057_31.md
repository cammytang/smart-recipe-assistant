# 完整菜谱套餐：用户需求：低脂不辣，现有食材 番茄 土豆

- **用户冰箱现有食材**：番茄、土豆。

---

## 4. **单菜详细做法**

### 1. 番茄炒土豆

#### 食材明细
- 番茄：1个
- 土豆：1个
- 盐：适量
- 食用油：适量

#### 分步烹饪步骤
1. 将番茄洗净切块，土豆去皮切片。
2. 热锅倒入食用油，加入土豆片翻炒至微黄。
3. 加入番茄块继续翻炒，炒至番茄出汁。
4. 根据口味加入适量盐调味，翻炒均匀即可出锅。

#### 烹饪小贴士
- 土豆切片后可先焯水，减少炒制时间。
- 番茄炒制过程中可加少量水，使口感更软嫩。

---

### 2. 土豆片炒番茄

#### 食材明细
- 土豆：1个
- 番茄：1个
- 盐：适量
- 食用油：适量

#### 分步烹饪步骤
1. 土豆去皮切片，番茄洗净切块。
2. 热锅倒入食用油，放入土豆片翻炒至微黄。
3. 加入番茄块一起翻炒，炒至番茄出汁。
4. 根据口味加入适量盐调味，翻炒均匀即可出锅。

#### 烹饪小贴士
- 土豆片可以提前焯水，避免炒制时间过长导致口感变硬。
- 番茄炒制时可加少许水，使味道更浓郁。

---

## 5. **厨房操作先后建议**
1. 先处理食材：将番茄和土豆清洗干净，分别切块或切片。
2. 热锅倒油，先炒土豆片，炒至微黄后加入番茄块。
3. 番茄炒出汁后，根据口味加入盐调味，翻炒均匀即可出锅。
4. 两道菜的烹饪过程相似，可同时进行，节省时间。

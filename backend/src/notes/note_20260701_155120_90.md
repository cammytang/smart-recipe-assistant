# 研究报告：低脂不辣，现有食材 番茄 土豆

```markdown
# 完整菜谱套餐：用户需求：低脂不辣，现有食材 番茄 土豆

## 1. **用餐需求总览**  
- 用户原始需求：低脂不辣  
- 忌口/过敏原：暂无相关信息  
- 用户现有食材：番茄、土豆  
- 整体用餐定位：一人食、快手晚餐  

## 2. **整套菜单概览表**  
| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|----------------|
| 番茄炒土豆   | 20分钟   | 简单 | 150大卡        |
| 土豆沙拉     | 15分钟   | 简单 | 120大卡        |

## 3. **分类采购清单**  
- 已有食材（无需额外购买）：  
  - 番茄  
  - 土豆  
- 需要采购食材：  
  - 暂无需要额外采购的食材  

## 4. **单菜详细做法**  
### 番茄炒土豆  
- **食材明细**：  
  - 番茄 1个  
  - 土豆 1个  
  - 盐 适量  
  - 食用油 1勺  
- **分步烹饪步骤**：  
  1. 土豆去皮切片，番茄洗净切块。  
  2. 热锅倒油，放入土豆片翻炒至微黄。  
  3. 加入番茄块继续翻炒，加入适量盐调味。  
  4. 炒至番茄出汁，土豆熟透即可出锅。  
- **烹饪小贴士**：  
  - 土豆切片后可浸泡在水中防止氧化变色。  
  - 番茄炒制时间不宜过长，以免失去口感。

### 土豆沙拉  
- **食材明细**：  
  - 土豆 1个  
  - 番茄 1个  
  - 盐 适量  
  - 黑胡椒 适量  
  - 橄榄油 1勺  
- **分步烹饪步骤**：  
  1. 土豆去皮煮熟，放凉后切块。  
  2. 番茄洗净切块，与土豆混合。  
  3. 加入盐、黑胡椒和橄榄油拌匀即可。  
- **烹饪小贴士**：  
  - 土豆煮熟后可稍微冷却再切块，避免碎裂。  
  - 沙拉中可加入少量柠檬汁提升风味。

## 5. **厨房操作先后建议**  
- 先处理土豆：将土豆去皮、切片或切块，准备炒制或煮熟。  
- 同时处理番茄：洗净切块，用于炒制或沙拉。  
- 烹饪顺序：先炒土豆，再加入番茄翻炒；或直接制作沙拉。  

## 6. **整体营养小结**  
- 总热量：约 270 大卡  
- 饮食适配评价：符合低脂不辣的饮食需求，富含膳食纤维和维生素，适合健康饮食。  
- 微调建议：可根据个人口味添加少量香草或蒜末增加风味。  

## 7. **饮食安全提醒**  
- 本套餐完全规避了用户忌口和过敏原，确保安全食用。
```

# 菜品 3: 土豆炖豆腐

### 菜品详细整理结果

#### 食材清单
- 土豆：1个
- 豆腐：半块
- 洋葱：半个
- 酱油：10ml
- 糖：5g
- 花生油：10ml

#### 烹饪步骤
1. 土豆去皮切块，洋葱切丝。
2. 热锅凉油，放入洋葱炒香。
3. 加入土豆块翻炒至微黄。
4. 倒入适量的水，加入酱油、糖和盐，煮沸。
5. 放入豆腐块，小火炖煮约15分钟。
6. 收汁后即可出锅。

#### 总耗时
约25分钟

#### 预估热量
约200大卡/人份

#### 难度
简单

#### 烹饪小贴士
1. 土豆切块后可以泡水防止氧化变黑。
2. 豆腐选择嫩豆腐更易入味。
3. 炖煮过程中可根据口味调整调料。

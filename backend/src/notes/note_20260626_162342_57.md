# 菜品 1: 番茄炒土豆

### 菜品详细整理结果

#### 食材清单
- 番茄：2个（约300克）
- 土豆：2个（约400克）
- 葱：适量
- 蒜：适量
- 盐：适量
- 生抽：1勺
- 醋：半勺
- 酱油：1勺
- 青辣椒：1个（可选）
- 油：适量

#### 烹饪步骤
1. 番茄用开水烫一下，去皮切块；土豆削皮后切成片或丝，放入清水中浸泡以防止氧化。
2. 锅中倒入油，加热至五成热后放入葱和蒜炒香。
3. 加入番茄块翻炒，直至番茄变软出汁。
4. 放入土豆片或丝，继续翻炒2-3分钟。
5. 加入青辣椒（如喜欢辣味），翻炒均匀。
6. 调味：加入盐、生抽、醋和酱油，翻炒均匀。
7. 炒至汤汁浓稠即可出锅。

#### 总耗时
约15-20分钟

#### 预估热量
约250-300大卡/份（根据具体用量调整）

#### 难度
简单（适合家庭厨房操作）

#### 烹饪小贴士
1. 土豆切片或丝后，建议用清水浸泡，避免氧化变色，并去除部分淀粉，使口感更佳。
2. 番茄去皮时，可以用开水烫一下，更容易剥皮。
3. 如果喜欢酸甜口味，可以适当加一点糖来平衡味道。
4. 炒制过程中，如果汤汁过多，可以适当收汁，使菜肴更入味。
5. 若想增加风味，可以加入少量的番茄酱或蚝油提鲜。

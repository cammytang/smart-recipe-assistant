# 完整菜谱套餐：用户需求：低脂不辣，现有食材 番茄 土豆

## 1. **用餐需求总览**  
- 用户原始需求：低脂不辣  
- 忌口/过敏原：暂无相关信息  
- 用户冰箱现有食材：番茄、土豆  
- 整体用餐定位：一人食、快手晚餐  

## 2. **整套菜单概览表**  
| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|---------------|
| 番茄炒土豆   | 20分钟   | 简单 | 150大卡       |
| 土豆片炒番茄 | 15分钟   | 简单 | 140大卡       |

## 3. **分类采购清单**  
- 已有食材（无需额外购买）：  
  - 番茄  
  - 土豆  
- 需要采购食材：  
  - 暂无需要额外采购的食材  

## 4. **单菜详细做法**  
### 番茄炒土豆  
- **食材明细**：  
  - 番茄 1个  
  - 土豆 1个  
  - 盐 适量  
  - 食用油 适量  
- **分步烹饪步骤**：  
  1. 土豆去皮切片，番茄洗净切块。  
  2. 热锅凉油，放入土豆片翻炒至微黄。  
  3. 加入番茄块，继续翻炒至番茄出汁。  
  4. 加盐调味，翻炒均匀后即可出锅。  
- **烹饪小贴士**：  
  - 土豆片可提前用清水浸泡，避免氧化变色。  
  - 番茄炒制时间不宜过长，以保持口感和营养。  

### 土豆片炒番茄  
- **食材明细**：  
  - 土豆 1个  
  - 番茄 1个  
  - 盐 适量  
  - 食用油 适量  
- **分步烹饪步骤**：  
  1. 土豆去皮切片，番茄洗净切块。  
  2. 热锅凉油，放入土豆片翻炒至微黄。  
  3. 加入番茄块，继续翻炒至番茄出汁。  
  4. 加盐调味，翻炒均匀后即可出锅。  
- **烹饪小贴士**：  
  - 土豆片可提前用清水浸泡，避免氧化变色。  
  - 番茄炒制时间不宜过长，以保持口感和营养。  

## 5. **厨房操作先后建议**  
- 先处理食材：将番茄和土豆清洗干净并切好。  
- 热锅凉油，先炒土豆片至微黄，再加入番茄块翻炒。  
- 最后加盐调味，翻炒均匀即可出锅。

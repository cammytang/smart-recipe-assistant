# 菜品 2: 土豆番茄汤

菜品详细整理结果

### 食材清单
- 番茄：2个（约200克）
- 土豆：1个（约200克）
- 盐：适量（约1小勺，5克）
- 橄榄油或食用油：适量（约2大勺）
- 葱花：少许（可选）
- 黑胡椒：少许（可选）
- 罗勒叶：几片（可选）
- 帕玛森奶酪：少许（可选）
- 细面条：少许（可选）

### 烹饪步骤
1. **准备食材**：番茄洗净去蒂切块，土豆去皮切片或小块，葱花、姜片备好。
2. **煸香调料**：热锅倒入适量油，放入葱花和姜片煸香。
3. **炒制蔬菜**：加入番茄块翻炒至出红汁，再加入土豆片翻炒均匀。
4. **加水煮沸**：倒入清水，水量没过食材约1公分，大火煮开后转中小火。
5. **炖煮**：煮约5-6分钟，直到土豆变软。
6. **调味**：加入盐、黑胡椒等调味料，搅拌均匀。
7. **收尾**：如果喜欢浓稠口感，可用搅拌机将汤打成泥；若喜欢清爽口感，直接享用即可。

### 总耗时
- 烹饪总耗时：约15-20分钟

### 预估热量
- 每份（约200克）热量：约80-100千卡（具体根据用油量和配料调整）

### 难度
- 制作难度：简单（适合家庭厨房操作）

### 烹饪小贴士
1. **番茄选择**：尽量选用自然熟的番茄，味道更浓郁，若使用罐装番茄，注意控制盐分。
2. **火候控制**：土豆煮至软烂即可，避免煮太久影响口感。
3. **食材替换**：若没有罗勒叶或帕玛森奶酪，可以省略或用其他香草代替，不影响整体风味。

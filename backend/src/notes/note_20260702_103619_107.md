4. **单菜详细做法**
### 番茄炒土豆
- **食材明细**：
  - 番茄 1个
  - 土豆 1个
  - 盐 少许
  - 食用油 适量
- **分步烹饪步骤**：
  1. 土豆去皮切片，番茄洗净切块。
  2. 热锅凉油，放入土豆片翻炒至微黄。
  3. 加入番茄块继续翻炒，加入少许盐调味。
  4. 炒至番茄出汁，土豆软熟即可出锅。
- **烹饪小贴士**：
  - 土豆片可提前浸泡在水中防止氧化变色。
  - 番茄炒制时间不宜过长，以免失去口感。

### 土豆片炒番茄
- **食材明细**：
  - 土豆 1个
  - 番茄 1个
  - 盐 少许
  - 食用油 适量
- **分步烹饪步骤**：

  2. 热锅凉油，放入土豆片翻炒至微黄。
  3. 加入番茄块继续翻炒，加入少许盐调味。
  4. 炒至番茄出汁，土豆软熟即可出锅。
- **烹饪小贴士**：
  - 土豆片可提前浸泡在水中防止氧化变色。
  - 番茄炒制时间不宜过长，以免失去口感。

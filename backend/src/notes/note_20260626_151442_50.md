# 研究报告：低脂不辣，现有食材 番茄 土豆，两菜一汤

<REPORT>
1. **用餐需求总览**  
   - 用户原始需求：低脂不辣  
   - 忌口/过敏原：暂无相关信息  
   - 现有食材：番茄、土豆  
   - 整体用餐定位：一人食，两菜一汤  

2. **整套菜单概览表**

| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|---------------|
| 番茄炒土豆   | 15分钟   | 中级 | 200-250大卡   |
| 清炒土豆丝   | 10分钟   | 简单 | 150大卡       |
| 番茄蛋花汤   | 10分钟   | 简单 | 100大卡       |

3. **分类采购清单**

  - 油  
  - 盐  
  - 生抽  
  - 青椒（可选）  
  - 鸡蛋  

- **需要采购食材**  
  - 暂无相关信息  

4. **单菜详细做法**

### 番茄炒土豆

- **食材明细**  
  - 土豆：2个（小的）  
  - 番茄：1个  
  - 葱：适量  
  - 蒜：适量  
  - 油：适量  
  - 盐：2克  
  - 生抽：10克  
  - 青椒：1个（可选）  

- **分步烹饪步骤**  
  1. 土豆去皮，洗净后切成细丝，用清水洗净土豆表面的淀粉，沥水备用。  
  2. 番茄去蒂，切成小块备用。  
  3. 青椒洗净去蒂去籽，切成细丝备用。  
  4. 起锅注入适量清水，加少许盐和油烧开，放入土豆丝，大火煮沸前放入青椒丝，煮沸后捞出沥水备用。  
  5. 再起锅热油，放入葱段和蒜末炒香。  
  6. 放入番茄炒匀，加入所有食材所需的盐，炒至番茄出汁水。  
  7. 放入土豆丝，翻炒至入味。  
  8. 淋入生抽，炒匀。  
  9. 出锅前撒上葱花，即可食用。  

- **烹饪小贴士**  
  1. 土豆丝切好后用清水冲洗几遍，洗去淀粉，这样口感更脆爽。  
  2. 番茄炒制时可以加入少许糖，中和酸味，提升整体风味。  
  3. 如果喜欢更浓郁的汤汁，可以在炒番茄时加入少量水或番茄酱。

### 清炒土豆丝

- **食材明细**  
  - 土豆：1个  
  - 盐：适量  
  - 油：适量  
  - 醋：少许（可选）  

- **分步烹饪步骤**  
  1. 土豆去皮切丝，用清水冲洗几遍去除淀粉。  
  2. 热锅倒油，放入土豆丝快速翻炒。  
  3. 加入适量盐调味，炒至土豆丝变软即可出锅。  
  4. 可根据口味加入少许醋提味。  

- **烹饪小贴士**  
  - 土豆丝切得越细，口感越脆。  
  - 炒制时火候要大，避免粘锅。

### 番茄蛋花汤

- **食材明细**  
  - 番茄：1个  
  - 鸡蛋：1个  
  - 盐：适量  
  - 油：适量  
  - 清水：500ml  

- **分步烹饪步骤**  
  1. 番茄洗净切块，鸡蛋打散备用。  
  2. 锅中加清水烧开，放入番茄块煮至软烂。  
  3. 倒入鸡蛋液，轻轻搅拌形成蛋花。  
  4. 加入适量盐调味，煮沸后即可关火。  

- **烹饪小贴士**  
  - 番茄煮的时间不宜过长，以免影响口感。  
  - 蛋花形成后立即关火，避免煮老。

5. **厨房操作先后建议**  
   - 先处理番茄和土豆，准备食材。  
   - 先做番茄蛋花汤，节省时间。  
   - 接着制作清炒土豆丝，最后炒番茄炒土豆。  
   - 整体下厨时间控制在35分钟以内。

6. **整体营养小结**  
   - 总热量：约450-500大卡  
   - 饮食适配评价：符合低脂不辣要求，适合健康饮食。  
   - 微调建议：可根据个人口味添加少量香菜或葱花提升风味。

7. **饮食安全提醒**  
   - 本套餐不含任何忌口或过敏食材，适合大多数人群食用。

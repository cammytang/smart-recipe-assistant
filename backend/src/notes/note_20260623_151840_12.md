# 4. **单菜详细做法**

## 快手家常炒蛋

### 食材明细

- 鸡蛋：3个  
- 番茄：1个（中等大小）  
- 土豆：1个（中等大小）  
- 生抽：1汤匙  
- 盐：适量  
- 食用油：1汤匙  

### 分步烹饪步骤

1. **准备食材**：
   - 番茄洗净切块，土豆去皮切片。
   - 鸡蛋打入碗中，加入少许盐，搅拌均匀。

2. **炒鸡蛋**：
   - 锅中倒入食用油，加热至微微冒烟。
   - 倒入打好的鸡蛋液，快速翻炒至凝固，盛出备用。

3. **炒蔬菜**：
   - 锅中再加少许油，放入土豆片翻炒至微黄。
   - 加入番茄块继续翻炒，炒至番茄出汁。

4. **混合调味**：
   - 将炒好的鸡蛋倒回锅中，与蔬菜一起翻炒均匀。
   - 沿锅边淋入生抽，撒上适量盐，翻炒均匀即可出锅。

### 烹饪小贴士

- 番茄和土豆的搭配可以增加菜品的口感层次。
- 若喜欢更清淡的口味，可减少生抽用量或使用低钠酱油。
- 炒制过程中注意火候，避免食材焦糊。

# 5. **厨房操作先后建议**

1. **备菜阶段**：

2. **烹饪顺序**：
   - 先炒鸡蛋，盛出备用。
   - 再炒土豆和番茄，最后将鸡蛋加入翻炒调味。

# 用户需求：两菜一汤，低脂不辣，现有食材 番茄 土豆

1. **用餐需求总览**
   - 用户原始需求：两菜一汤，低脂不辣。
   - 忌口/过敏原：暂无相关信息。
   - 用户现有食材：番茄、土豆。
   - 整体用餐定位：低脂健康餐，适合一人食或家庭餐。

2. **整套菜单概览表**

| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|---------------|
| 番茄炒蛋     | 15分钟   | 简单 | 250大卡       |
| 土豆炖鸡     | 40分钟   | 中等 | 350大卡       |
| 清汤豆腐     | 20分钟   | 简单 | 180大卡       |

3. **分类采购清单**

- **已有食材（无需额外购买）**
  - 番茄
  - 土豆

- **需要采购食材**
  - 鸡肉：300g（用于土豆炖鸡）
  - 鸡蛋：2个（用于番茄炒蛋）
  - 盐：4g（用于番茄炒蛋）
  - 胡椒粉：1g（用于番茄炒蛋）

4. **单菜详细做法**

### 番茄炒蛋
- **食材明细**
  - 番茄：1个
  - 鸡蛋：2个
  - 盐：2g
  - 胡椒粉：0.5g

- **分步烹饪步骤**
  1. 番茄洗净切块，鸡蛋打散备用。
  2. 热锅凉油，倒入鸡蛋液翻炒至凝固后盛出。
  3. 锅中再加少许油，放入番茄翻炒至软烂。
  4. 加入炒好的鸡蛋，调入盐和胡椒粉，翻炒均匀即可。

- **烹饪小贴士**
  - 可以加入少量糖提鲜，但需控制量以保持低脂。
  - 若喜欢口感更嫩，可先将番茄稍微焯水去皮。

### 土豆炖鸡
- **食材明细**
  - 土豆：1个
  - 鸡肉：300g
  - 盐：适量
  - 胡椒粉：适量

- **分步烹饪步骤**
  1. 土豆去皮切块，鸡肉切块并焯水去腥。
  2. 热锅凉油，将鸡肉炒至变色后加入土豆块翻炒。
  3. 加入适量清水，盖上锅盖炖煮约20分钟。
  4. 最后调入盐和胡椒粉，搅拌均匀即可。

- **烹饪小贴士**
  - 可根据口味加入少量葱姜提香。
  - 慢炖能更好地保留鸡肉的营养和风味。

### 清汤豆腐
- **食材明细**
  - 豆腐：1块
  - 盐：适量
  - 胡椒粉：适量

- **分步烹饪步骤**
  1. 豆腐切块，放入沸水中焯水1分钟去腥。
  2. 将豆腐放入汤锅中，加入适量清水煮沸。
  3. 调入盐和胡椒粉，煮10分钟即可。

- **烹饪小贴士**
  - 可加入一些青菜或香菇增加口感和营养。
  - 清汤豆腐清淡爽口，适合搭配主菜食用。

5. **厨房操作先后建议**

- **备菜顺序**
  1. 先处理番茄和土豆，切块备用。
  2. 准备鸡蛋和鸡肉，提前焯水。
  3. 备好调料（盐、胡椒粉）。

- **烹饪顺序**
  1. 先做清汤豆腐，利用炖煮时间准备其他菜品。
  2. 接着制作番茄炒蛋，快速完成。
  3. 最后进行土豆炖鸡，慢炖过程中可休息或准备餐具。

6. **整体营养小结**

- **总热量**：约780大卡
- **饮食适配评价**：符合低脂不辣需求，营养均衡，适合健康饮食。
- **微调建议**：可根据个人口味添加少量蔬菜或菌菇丰富口感。

7. **饮食安全提醒**

- **规避忌口/过敏原**：本套餐未涉及任何用户提及的忌口或过敏原，可放心食用。

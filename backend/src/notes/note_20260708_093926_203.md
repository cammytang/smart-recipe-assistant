# 菜品 2: 土豆汤

### 菜品详细整理结果

#### 食材清单
- 土豆：2个（约500克）
- 番茄：1个（约150克）
- 洋葱：半个（约50克）
- 大蒜：2瓣
- 盐：适量
- 黑胡椒：适量
- 食用油：1汤匙（约15毫升）
- 清水：500毫升

#### 烹饪步骤
1. **准备食材**：将土豆去皮切块，番茄切丁，洋葱切丝，大蒜切末。
2. **炒香底料**：热锅加食用油，放入洋葱和大蒜炒香。
3. **加入土豆**：将土豆块加入锅中翻炒几分钟。
4. **加水煮沸**：倒入清水，大火煮沸后转小火炖煮15分钟。
5. **加入番茄**：放入番茄丁，继续炖煮10分钟。
6. **调味**：根据口味加入盐和黑胡椒，搅拌均匀。
7. **出锅**：待汤汁浓稠后即可盛出。

#### 总耗时
- 总烹饪时长：约30分钟

#### 预估热量
- 整道菜的预估热量：约150大卡

#### 难度
- 制作难度：★★★（中等）

#### 烹饪小贴士
1. **土豆选择**：选用新鲜、无发芽的土豆，避免口感变差。
2. **火候控制**：炖煮过程中注意火候，避免汤汁烧干。
3. **食材替换**：若没有番茄，可使用胡萝卜或南瓜代替，增加风味。

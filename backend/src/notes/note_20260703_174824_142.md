# 用户需求：低脂不辣，现有食材 番茄 土豆 ，要辣的口味

   - 整体用餐定位：家庭餐，适合快手晚餐，兼顾低脂和微辣口味。

4. **单菜详细做法**

### 番茄土豆炖

- **食材明细**
  - 番茄：2个（约300g）
  - 土豆：2个（约300g）
  - 盐：适量
  - 黑胡椒：少许
  - 食用油：适量

- **分步烹饪步骤**
  1. 将番茄洗净切块，土豆去皮切块。
  2. 热锅加少量食用油，放入番茄翻炒至出汁。
  3. 加入土豆块，继续翻炒均匀。
  4. 加入适量水，盖上锅盖焖煮10分钟。
  5. 根据口味加入盐和黑胡椒调味，搅拌均匀即可。

- **烹饪小贴士**
  - 可以根据个人喜好加入少量香料如八角或桂皮增加风味。
  - 若喜欢更浓郁的口感，可加入少量番茄酱提升味道。

### 炒番茄土豆

- **食材明细**
  - 番茄：2个（约300g）
  - 土豆：2个（约300g）
  - 青椒：0.5个
  - 红椒：0.5个
  - 干辣椒：3个
  - 大蒜：4瓣
  - 葱：1根
  - 生抽：5ml
  - 陈醋：10ml
  - 盐：2g
  - 食用油：10-15ml
  - 猪肉：200g
  - 姜：1块（约5g）
  - 蒜：3瓣（约12g）
  - 酱油：6-10ml
  - 土豆淀粉：5g
  - 水：15g

- **分步烹饪步骤**
  1. 番茄洗净切块，土豆去皮切片，青椒、红椒切丝，干辣椒剪段，大蒜切末，葱切段，姜切片。
  2. 热锅加油，放入干辣椒、姜片、蒜末爆香。
  3. 加入猪肉翻炒至变色，再加入番茄、土豆、青椒、红椒一起翻炒。
  4. 加入生抽、酱油、陈醋、盐调味，翻炒均匀。
  5. 最后加入水和土豆淀粉勾芡，翻炒至汤汁浓稠即可出锅。

- **烹饪小贴士**
  - 炒制过程中注意火候，避免食材焦糊。
  - 若喜欢更辣的口味，可适当增加干辣椒的数量。

5. **厨房操作先后建议**
  - 先准备食材：将番茄、土豆、青椒、红椒等清洗干净并切好。
  - 然后开始制作“番茄土豆炖”，先炒番茄，再加入土豆焖煮。
  - 同时可以准备“炒番茄土豆”的食材，待炖菜完成后，开始炒制番茄土豆。
  - 最后根据口味调整调味，确保两道菜都达到最佳口感。

6. **整体营养小结**

  - 微调建议：若希望更清淡，可减少食用油用量；若喜欢更辣，可增加干辣椒数量。

# 4. **单菜详细做法**

## 番茄炒土豆

### 食材明细
- 番茄 1个（约150g）
- 土豆 1个（约150g）
- 青椒 0.5个
- 红椒 0.5个
- 干辣椒 3个
- 葱 1根
- 生抽 5ml
- 陈醋 10ml
- 盐 2g
- 食用油 10-15ml
- 大蒜 4瓣
- 猪肉 200g
- 土豆淀粉 5g
- 水 15g

### 分步烹饪步骤
1. 将番茄洗净切块，土豆去皮切片，青椒和红椒切丝，干辣椒剪段，葱切末，大蒜切末。
2. 热锅倒油，加入葱、蒜、干辣椒爆香。
3. 加入猪肉翻炒至变色，再加入番茄、土豆、青椒、红椒继续翻炒。
4. 加入生抽、陈醋、盐调味，翻炒均匀。
5. 倒入水，盖上锅盖焖煮5分钟。
6. 最后加入土豆淀粉勾芡，翻炒均匀即可出锅。

### 烹饪小贴士
- 番茄炒土豆时可适当加点水，使口感更软糯。
- 若喜欢更浓郁的酱汁，可适量增加生抽或陈醋的用量。

---

## 土豆泥

### 食材明细
- 土豆 1个（约150g）
- 茄子 1个（约150g）
- 肉量 180g
- 酱油 15ml
- 盐 5g
- 辣椒 50g（调味）
- 蒜 3瓣（调味）

### 分步烹饪步骤
1. 土豆去皮蒸熟，茄子去皮蒸熟，分别捣成泥状。
2. 肉类切丁，加入酱油、盐、蒜末腌制10分钟。
3. 热锅倒油，将腌好的肉丁炒熟，加入土豆泥和茄子泥翻炒均匀。
4. 最后加入辣椒调味，翻炒均匀即可出锅。

### 烹饪小贴士
- 土豆泥可以加入少量牛奶或奶油提升口感。
- 若想让味道更丰富，可加入一些香料如黑胡椒或香叶。

# 5. **厨房操作先后建议**

1. **备菜阶段**：
   - 先处理番茄和土豆，切块备用。
   - 准备青椒、红椒、干辣椒、葱、蒜等配料。
   - 肉类提前腌制。

2. **烹饪顺序**：
   - 先做番茄炒土豆，因为需要较短时间完成。
   - 接着制作土豆泥，耗时较长，可在番茄炒土豆完成后进行。

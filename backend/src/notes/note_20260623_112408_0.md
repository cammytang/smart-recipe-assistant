# 完整菜谱套餐：低脂不辣，现有食材 番茄 土豆

低脂不辣，现有食材 番茄 土豆 全套菜谱报告

1. **用餐需求总览**
- 原始需求：用户希望制作一道低脂、不辣的家常菜，适合快手烹饪。
- 饮食定位：减脂/一人食/快手晚餐。
- 忌口/过敏原：暂无相关信息。
- 用户自有食材：番茄、土豆。
- 其他要求：菜品需简单易做，适配低脂饮食。

2. **整套菜单概览表**
| 菜名         | 制作时长 | 难度 | 单菜预估热量（kcal） |
|--------------|----------|------|------------------------|
| 快手家常炒蛋 | 10分钟   | 简单 | 150                    |

3. **分类采购清单**
### 已有食材（无需额外购买）
- 番茄
- 土豆
### 需要采购食材
- 鸡蛋（根据实际需要购买，建议2-3个）
- 食用油（少量，约1汤匙）
- 盐（适量）

4. **单菜详细做法**
### 快手家常炒蛋
#### 食材明细
- 番茄：1个（中等大小）
- 土豆：1个（中等大小）
- 鸡蛋：2-3个
- 食用油：1汤匙
- 盐：适量
#### 分步烹饪步骤
1. 准备食材：番茄洗净切块，土豆去皮后切片或小块。鸡蛋打入碗中，加入少许盐搅拌均匀。
2. 炒蛋：热锅凉油，倒入鸡蛋液，快速翻炒至凝固，盛出备用。
3. 炒蔬菜：锅中再加少许油，放入番茄和土豆翻炒，炒至软熟。
4. 混合调味：将炒好的鸡蛋倒回锅中，与蔬菜一起翻炒均匀，加入适量盐调味。
5. 出锅装盘：炒至食材充分融合，即可出锅装盘。
#### 烹饪小贴士
- 番茄和土豆可以提前切好，节省时间。
- 若喜欢口感更丰富，可加入少许葱花提香。
- 选用不粘锅可减少用油量，更符合低脂需求。

5. **厨房操作先后建议**
1. 备菜阶段：洗净并切好番茄和土豆。打散鸡蛋，加入盐搅拌均匀。
2. 烹饪顺序：先炒鸡蛋，盛出备用。再炒番茄和土豆，炒至软熟。最后将鸡蛋倒回锅中，与蔬菜混合翻炒，调味后出锅。

6. **整体营养小结**
- 总热量：约150 kcal（基于2-3个鸡蛋和少量油）
- 饮食适配评价：该菜品符合低脂、不辣的饮食需求，富含蛋白质和膳食纤维，适合减脂期食用。
- 微调建议：可以增加一些绿叶蔬菜（如菠菜）提升维生素含量。若追求更低脂，可用橄榄油替代普通食用油。

# 研究报告：低脂不辣，现有食材 番茄 土豆

<REPORT>
1. **用餐需求总览**  
   - 用户原始需求：低脂不辣  
   - 忌口/过敏原：无  
   - 用户现有食材：番茄、土豆  
   - 整体用餐定位：家庭餐，利用现有食材制作清淡低脂菜品  

2. **整套菜单概览表**  
| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|---------------|
| 番茄炒土豆   | 20分钟   | 简单 | 150大卡       |
| 土豆番茄汤   | 30分钟   | 中等 | 120大卡       |

3. **分类采购清单**  
- 已有食材（无需额外购买）：  
  - 番茄  
  - 土豆  

- 需要采购食材：  
  - 暂无需要额外采购的食材  

4. **单菜详细做法**  
### 番茄炒土豆  
- **食材明细**  
  - 番茄 2个  
  - 土豆 1个  
  - 盐 适量  
  - 食用油 1勺  

- **分步烹饪步骤**  
  1. 土豆去皮切片，番茄洗净切块。  
  2. 热锅加少量食用油，放入土豆片翻炒至微黄。  
  3. 加入番茄块继续翻炒，加入适量盐调味。  
  4. 炒至番茄出汁，土豆熟透即可出锅。  

- **烹饪小贴士**  
  - 土豆切片后可用水泡一下，减少氧化变色。  
  - 番茄炒制时间不宜过长，以保持口感鲜嫩。  

### 土豆番茄汤  
- **食材明细**  
  - 番茄 2个  
  - 土豆 1个  
  - 清水 500ml  
  - 盐 适量  
  - 食用油 1勺  

- **分步烹饪步骤**  
  1. 土豆去皮切块，番茄洗净切块。  
  2. 热锅加少量食用油，放入土豆块翻炒至微黄。  
  3. 加入番茄块和清水，煮沸后转小火炖煮10分钟。  
  4. 加入适量盐调味，搅拌均匀即可出锅。  

- **烹饪小贴士**  
  - 可根据口味加入少许香叶或百里香增加风味。  
  - 若喜欢更浓稠的口感，可适当减少水量。  

5. **厨房操作先后建议**  
   - 先准备食材：将番茄和土豆清洗干净并切好。  
   - 先做“番茄炒土豆”，耗时较短，可先完成。  
   - 接着制作“土豆番茄汤”，在等待汤煮的过程中可以准备其他事项。  

6. **整体营养小结**  
   - 总热量：约270大卡  
   - 饮食适配评价：符合低脂不辣的饮食需求，适合健康饮食人群。  
   - 微调建议：若希望增加蛋白质摄入，可添加少量鸡胸肉或豆腐。  

7. **饮食安全提醒**  
   - 本套餐中未使用任何忌口或过敏原食材，完全符合用户需求。
</REPORT>

# 单菜详细做法

## 快手家常炒蛋

### 食材明细
- 鸡蛋 2个
- 番茄 1个
- 土豆 1个
- 盐 少许
- 食用油 适量

### 分步烹饪步骤
1. 番茄和土豆洗净，切成小块备用。
2. 鸡蛋打入碗中，加入少许盐，搅拌均匀。
3. 锅中倒入适量食用油，加热后倒入鸡蛋液，翻炒至凝固后盛出备用。
4. 锅中再加少许油，放入番茄和土豆翻炒至软。
5. 倒入炒好的鸡蛋，快速翻炒均匀，调味后即可出锅。

### 烹饪小贴士
- 番茄和土豆可以提前切好，节省时间。
- 若喜欢口感更嫩，可将鸡蛋液稍微打散后再炒。

---

# 厨房操作先后建议

1. 准备食材：番茄和土豆洗净切块，鸡蛋打散。
2. 先炒鸡蛋，盛出备用。
3. 再炒番茄和土豆，最后加入鸡蛋翻炒均匀。

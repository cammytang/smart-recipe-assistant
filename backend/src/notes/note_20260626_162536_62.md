# 用户需求：低脂不辣，现有食材 番茄 土豆

1. **用餐需求总览**
   - 用户原始需求：低脂不辣
   - 忌口/过敏原：暂无相关信息
   - 用户冰箱现有食材：番茄、土豆
   - 整体用餐定位：一人食、快手晚餐

2. **整套菜单概览表**
| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|----------------|
| 番茄炒土豆   | 20分钟   | 简单 | 200大卡        |
| 土豆片炒番茄 | 25分钟   | 简单 | 220大卡        |

3. **分类采购清单**
   - 已有食材（无需额外购买）：
     - 番茄
     - 土豆
   - 需要采购食材：
     - 暂无需要额外采购的食材

4. **单菜详细做法**
### 番茄炒土豆
- **食材明细**：
  - 番茄 2个
  - 土豆 1个
  - 盐 适量
  - 食用油 适量
- **分步烹饪步骤**：
  1. 土豆去皮切片，番茄洗净切块。
  2. 热锅倒入食用油，放入土豆片翻炒至微黄。
  3. 加入番茄块继续翻炒，加入适量盐调味。
  4. 炒至番茄出汁，土豆熟透即可出锅。
- **烹饪小贴士**：
  - 土豆片可提前浸泡在水中防止氧化变色。
  - 番茄炒制时间不宜过长，以免失去口感。

### 土豆片炒番茄
- **食材明细**：
  - 土豆片 100克
  - 番茄 2个
  - 盐 适量
  - 食用油 适量
- **分步烹饪步骤**：
  1. 土豆切片，番茄洗净切块。
  2. 热锅倒入食用油，放入土豆片翻炒至微黄。
  3. 加入番茄块继续翻炒，加入适量盐调味。
  4. 炒至番茄出汁，土豆熟透即可出锅。
- **烹饪小贴士**：
  - 土豆片可提前浸泡在水中防止氧化变色。
  - 番茄炒制时间不宜过长，以免失去口感。

5. **厨房操作先后建议**
   - 先处理食材：将番茄和土豆清洗干净并切好。
   - 同时开始烹饪两道菜，先炒土豆片，再炒番茄。
   - 确保每道菜的烹饪时间合理，避免等待。

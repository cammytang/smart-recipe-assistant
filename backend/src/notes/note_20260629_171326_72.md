## 4. **单菜详细做法**

### 番茄炒土豆

- **食材明细**  
  - 番茄 1个  
  - 土豆 1个  
  - 盐 少许  
  - 食用油 适量  

- **分步烹饪步骤**  
  1. 土豆去皮切片，番茄洗净切块。  
  2. 热锅凉油，放入土豆片翻炒至微黄。  
  3. 加入番茄块，继续翻炒至番茄出汁。  
  4. 加盐调味，翻炒均匀后即可出锅。

- **烹饪小贴士**  
  - 土豆切片后可浸泡在水中防止氧化变色。  
  - 番茄炒制时间不宜过长，以保持口感鲜嫩。

### 清炒土豆丝

- **食材明细**  
  - 土豆 1个  
  - 盐 少许  
  - 食用油 适量  

- **分步烹饪步骤**  
  1. 土豆去皮切丝，用清水冲洗干净，沥干水分。  
  2. 热锅凉油，放入土豆丝快速翻炒。  
  3. 加盐调味，炒至土豆丝变软即可出锅。

- **烹饪小贴士**  
  - 土豆丝尽量切得细且均匀，这样更容易炒熟。  
  - 炒制过程中火候要适中，避免焦糊。

### 番茄蛋花汤

- **食材明细**  
  - 番茄 1个  
  - 鸡蛋 1个  
  - 盐 少许  
  - 食用油 适量  
  - 葱花 10g  

- **分步烹饪步骤**  
  1. 番茄洗净切块，鸡蛋打散备用。  
  2. 锅中加水烧开，放入番茄煮至出汁。  
  3. 倒入鸡蛋液，轻轻搅拌形成蛋花。  
  4. 加盐调味，煮沸后即可关火。  
  5. 撒上葱花即可食用。

- **烹饪小贴士**  
  - 番茄煮的时间不宜过长，以免影响口感。  
  - 鸡蛋液倒入时要缓慢，有助于形成细腻的蛋花。

## 5. **厨房操作先后建议**  
- 先处理番茄和土豆，准备食材。  
- 然后依次进行番茄炒土豆、清炒土豆丝和番茄蛋花汤的制作。  
- 番茄蛋花汤最后制作，确保汤品新鲜。

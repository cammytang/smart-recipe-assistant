# 4. **单菜详细做法**

## 番茄炒土豆

### 食材明细

- 番茄 2个
- 土豆 1个
- 盐 适量
- 食用油 适量

### 分步烹饪步骤

1. 将番茄洗净切块，土豆去皮切片。
2. 热锅倒入食用油，加入土豆片翻炒至微黄。
3. 加入番茄块继续翻炒，直至番茄出汁。
4. 根据口味加入适量盐调味，翻炒均匀即可。

### 烹饪小贴士

- 土豆切片后可浸泡在水中防止氧化变色。
- 番茄炒制时间不宜过长，以免失去口感。

---

## 土豆片汤

### 食材明细

- 土豆 1个（约200克）
- 番茄 1个（约150克）
- 油 适量（建议使用橄榄油或食用油）
- 盐 适量
- 黑胡椒 少许
- 姜 少许（可选）
- 水 适量

### 分步烹饪步骤

1. 清洗番茄和土豆。番茄去蒂切块，土豆去皮切片。
2. 热锅入油，放入番茄块小火煸炒，待番茄出红汁，稍熟软后盛出。
3. 锅添油，放入土豆片翻炒，待出香味炒匀后，直接加入清水，盖上锅盖，开中火烧。
4. 等土豆片煮熟后，开盖加入炒过的番茄，再煮1分钟左右。
5. 关火，加盐调味，把汤味搅匀就可以了。

### 烹饪小贴士

1. 如果希望汤更浓稠，可以适当减少水量或使用搅拌机将食材打碎。
2. 番茄选择成熟度高的会更甜，口感更好。
3. 若喜欢更丰富的味道，可以加入少量姜片或黑胡椒提味。

---

# 5. **厨房操作先后建议**

1. 先准备食材：将番茄和土豆清洗干净并切好。
2. 先做“番茄炒土豆”，因为其烹饪时间较短，可以先完成。
3. 接着制作“土豆片汤”，利用剩余的番茄和土豆，节省备料时间。

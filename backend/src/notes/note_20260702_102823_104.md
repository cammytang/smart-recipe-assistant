# 研究报告：低脂不辣，现有食材 番茄 土豆

4. **单菜详细做法**  

### 番茄炒土豆  
**食材明细**：  
- 番茄：2个（约300克）  
- 土豆：2个（约400克）  
- 食用油：适量（建议使用橄榄油或菜籽油，低脂健康）  
- 盐：适量  
- 白胡椒粉：少许（可选）  
- 生抽：1勺（约5毫升）  
- 糖：少许（可选，用于中和番茄的酸味）  

**分步烹饪步骤**：  
1. **准备食材**：将番茄洗净后切块，土豆去皮后切成小块，放入清水中浸泡以防止氧化变色。  
2. **焯水处理**：将土豆块放入加了少许盐的开水中焯烫2-3分钟，捞出备用。  
3. **炒制番茄**：热锅凉油，加入适量食用油，放入番茄块翻炒至出汁，加入少许盐和糖（可选）调味。  
4. **加入土豆**：将焯好的土豆块加入锅中，与番茄一起翻炒均匀。  
5. **调味**：加入生抽、白胡椒粉（可选），继续翻炒均匀。  
6. **炖煮**：加入适量清水，水量没过食材，大火烧开后转小火炖煮10-15分钟，直至土豆熟透。  
7. **收汁**：根据个人口味调整盐量，最后大火收汁至汤汁浓稠即可。  

**烹饪小贴士**：  
- **避免土豆变色**：土豆切块后可以放入清水中浸泡，防止氧化变色。  
- **控制火候**：番茄炒制时火候不宜过大，以免糊锅。  
- **替代建议**：如果喜欢更清淡的口感，可以用少量橄榄油代替食用油，或者直接水煮。  

### 土豆片炒番茄  
**食材明细**：  
- 土豆：1个  
- 番茄：1个  
- 盐：适量  
- 食用油：适量  

**分步烹饪步骤**：  
1. 土豆去皮切片，番茄洗净切块。  
2. 热锅凉油，放入土豆片翻炒至微黄。  
3. 加入番茄块继续翻炒，加入少许盐调味。  
4. 炒至番茄出汁，土豆熟透即可出锅。  

**烹饪小贴士**：  
- 土豆片可提前用清水浸泡，避免氧化变色。  
- 番茄炒制时间不宜过长，以保持口感和营养。  

5. **厨房操作先后建议**  
- 先处理食材：将番茄和土豆清洗干净并切好。  
- 同时开始烹饪两道菜，先炒土豆片，再炒番茄。  
- 两道菜制作时间相近，可同时进行，节省整体下厨时间。  

6. **整体营养小结**  
- 总热量：约240-300大卡（2人份）  
- 饮食适配评价：符合低脂不辣的要求，适合健康饮食人群。  
- 微调建议：可根据个人口味添加少量香料或蔬菜提升风味。  

7. **饮食安全提醒**  
- 本套餐完全规避了用户忌口和过敏原，确保安全食用。

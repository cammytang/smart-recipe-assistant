## 4. **单菜详细做法**  
### 番茄土豆汤  
**食材明细**  
- 番茄 2个  
- 土豆 1个  
- 盐 适量  
- 黑胡椒 少许  
- 橄榄油 1勺（可选）  

**分步烹饪步骤**  
1. 番茄洗净切块，土豆去皮切片。  
2. 锅中加入少量橄榄油，放入番茄翻炒至出汁。  
3. 加入土豆片和适量清水，煮沸后转小火炖煮10分钟。  
4. 加盐和黑胡椒调味，搅拌均匀即可。  

**烹饪小贴士**  
- 可根据口味添加少许香叶或百里香提升风味。  
- 若喜欢更浓郁口感，可加入少量牛奶或淡奶油。  

### 炒番茄土豆片  
**食材明细**  
- 番茄 1个  
- 土豆 1个  
- 盐 适量  
- 黑胡椒 少许  
- 橄榄油 1勺  

**分步烹饪步骤**  
1. 番茄洗净切片，土豆去皮切片。  
2. 锅中加入橄榄油，放入土豆片翻炒至微黄。  
3. 加入番茄片继续翻炒，至番茄软烂。  
4. 加盐和黑胡椒调味，翻炒均匀即可出锅。  

**烹饪小贴士**  
- 番茄炒制时间不宜过长，以免失去酸甜口感。  
- 可搭配少量蒜末提味。  

## 5. **厨房操作先后建议**  
- 先准备番茄土豆汤：先处理番茄和土豆，提前炖煮。  
- 同时准备炒番茄土豆片：在汤炖煮的同时，快速翻炒番茄和土豆片。  
- 最后统一装盘，确保菜品新鲜热乎。

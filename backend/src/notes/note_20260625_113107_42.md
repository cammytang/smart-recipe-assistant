## 4. **单菜详细做法**

### 快手家常炒蛋

#### 食材明细
- 鸡蛋：3个
- 盐：适量
- 食用油：适量
- 生抽：少许（可选）
- 葱花：少许（可选）

#### 分步烹饪步骤
1. 准备鸡蛋：将鸡蛋打入碗中，加入适量盐，搅拌均匀。
2. 热锅凉油：在锅中倒入适量食用油，加热至油温适中。
3. 倒入鸡蛋液：将鸡蛋液倒入锅中，快速翻炒至凝固。
4. 加入调味料：根据个人口味加入生抽和葱花，继续翻炒均匀。
5. 出锅装盘：炒好后盛出，即可上桌。

#### 烹饪小贴士
- 炒蛋时火候不宜过大，避免炒糊。
- 可根据喜好加入蔬菜或火腿等配料增加口感。

### 4. **单菜详细做法**

#### 🍳 番茄炒蛋

**食材明细**：
- 番茄 1个
- 鸡蛋 1-2个
- 盐 15g
- 胡椒粉 0.5g/人
- 香油 2滴
- 味素 5g（可选）
- 西红柿 1个
- 葱 适量
- 姜 适量
- 蒜 15g
- 食用油 4ml/个
- 糖 0-2g/人
- 葱花 0-10g/人

**分步烹饪步骤**：
1. 番茄洗净切块，鸡蛋打散备用。
2. 热锅凉油，放入蒜末爆香。
3. 加入番茄翻炒至出汁。
4. 倒入鸡蛋液，快速翻炒均匀。
5. 根据口味加入盐、胡椒粉、糖和味素。
6. 出锅前淋上香油，撒上葱花即可。

**烹饪小贴士**：
- 番茄炒蛋的关键是火候控制，避免炒过头变老。
- 若喜欢酸甜口感，可适当加一点糖。

---

#### 🍲 土豆炖豆腐

**食材明细**：
- 肋排 750g
- 土豆 300g
- 姜 30g（分为两份：15g焯水用，15g炒制用）
- 小葱 25g（分为两份：15g打成葱结，10g切葱花）
- 料酒 25ml（分为两份：15ml焯水用，10ml炒制用）
- 白糖 10g
- 干辣椒 5g
- 八角 1g
- 花椒 1g
- 桂皮 1g
- 生抽 10ml
- 老抽 5ml
- 蚝油 5ml
- 黄豆酱 5g
- 盐 3g
- 开水 700ml
- 食用油 20ml

**分步烹饪步骤**：
1. 肋排洗净，冷水下锅焯水，加入姜片和料酒，煮沸后撇去浮沫，捞出沥干。
2. 土豆去皮切块，豆腐切块备用。
3. 热锅凉油，放入姜片、八角、花椒、桂皮、干辣椒炒香。
4. 加入肋排翻炒，加入生抽、老抽、蚝油、黄豆酱继续翻炒。
5. 倒入开水，加入白糖，大火烧开后转小火炖煮30分钟。
6. 加入土豆和豆腐，继续炖煮15分钟。
7. 最后根据口味加入盐调味，撒上葱花即可。

**烹饪小贴士**：
- 土豆炖豆腐的汤汁浓郁，建议炖煮时间充足，让食材充分吸收味道。
- 若喜欢更鲜美的口感，可加入少量鸡精提鲜。

---

#### 🥣 紫菜蛋花汤

**食材明细**：
- 干紫菜 10g
- 鸡蛋 2个
- 盐 2g

**分步烹饪步骤**：
1. 紫菜用清水泡发，洗净备用。
2. 锅中加水烧开，放入紫菜煮1分钟。
3. 打入鸡蛋液，快速搅拌成蛋花。
4. 加入盐调味，煮1分钟后即可出锅。

**烹饪小贴士**：
- 紫菜蛋花汤简单快捷，适合搭配主菜食用。
- 若喜欢更鲜美，可加入少许虾皮或海米提鲜。

### 5. **厨房操作先后建议**

1. **备菜阶段**：
   - 提前将番茄、土豆、豆腐、紫菜等食材处理好。
   - 鸡蛋打散备用，葱姜蒜切好。

2. **先做紫菜蛋花汤**：
   - 紫菜蛋花汤制作时间短，可在其他菜品准备期间完成。

3. **接着做番茄炒蛋**：
   - 番茄炒蛋需要较短时间，且操作简单，适合在中间进行。

4. **最后炖煮土豆炖豆腐**：
   - 土豆炖豆腐需要较长时间炖煮，建议在最后进行，确保汤汁浓郁。

# 用户需求：低脂不辣，现有食材 番茄 土豆

1. **用餐需求总览**
   - 用户原始需求：低脂不辣
   - 忌口/过敏原：暂无相关信息
   - 用户冰箱现有食材：番茄、土豆
   - 整体用餐定位：低脂、家常、快手晚餐

2. **整套菜单概览表**
   | 菜名         | 制作时长 | 难度 | 单菜预估热量 |
   |--------------|----------|------|---------------|
   | 番茄土豆汤   | 30分钟   | 简单 | 150大卡       |
   | 炒番茄土豆片 | 20分钟   | 简单 | 120大卡       |

3. **分类采购清单**
   - 已有食材（无需额外购买）：
     - 番茄
     - 土豆
   - 需要采购食材：
     - 暂无需要额外采购的食材

4. **单菜详细做法**
   ### 番茄土豆汤
   - **食材明细**：
     - 番茄 2个
     - 土豆 1个
     - 盐 适量
     - 黑胡椒 少许
     - 清水 500ml
   - **分步烹饪步骤**：
     1. 番茄洗净切块，土豆去皮切片。
     2. 锅中加清水煮沸后加入土豆片，煮约10分钟至软。
     3. 加入番茄块，继续煮5分钟。
     4. 根据口味加入盐和黑胡椒调味即可。
   - **烹饪小贴士**：
     - 可以根据个人喜好加入少量橄榄油增加风味。
     - 若喜欢更浓郁的口感，可加入少许牛奶或淡奶油。

   ### 炒番茄土豆片
   - **食材明细**：
     - 番茄 1个
     - 土豆 1个
     - 盐 适量
     - 黑胡椒 少许
     - 食用油 1勺
   - **分步烹饪步骤**：
     1. 番茄洗净切片，土豆去皮切片。
     2. 热锅加食用油，放入土豆片翻炒至微黄。
     3. 加入番茄片，继续翻炒至番茄出汁。
     4. 根据口味加入盐和黑胡椒调味即可。
   - **烹饪小贴士**：
     - 炒制过程中注意火候，避免土豆焦糊。
     - 若喜欢更清爽的口感，可减少食用油用量。

5. **厨房操作先后建议**
   - 先准备番茄土豆汤：先将土豆煮熟，再加入番茄煮制。
   - 同时准备炒番茄土豆片：在番茄土豆汤煮制的同时，开始炒制番茄土豆片。
   - 最后统一装盘，搭配食用。

6. **整体营养小结**
   - 整套菜单总热量：约270大卡
   - 饮食适配评价：符合低脂不辣的需求，利用现有食材制作，简单快捷且营养均衡。
   - 微调建议：若希望增加蛋白质摄入，可添加少量鸡胸肉或豆腐。

7. **饮食安全提醒**
   - 本套餐完全规避了用户忌口及过敏原，确保安全食用。

# 研究报告：低脂不辣，现有食材 番茄 土豆

```markdown
# 完整菜谱套餐：用户需求：低脂不辣，现有食材 番茄 土豆

## 1. **用餐需求总览**  
- 用户原始需求：低脂不辣  
- 忌口/过敏原：暂无相关信息  
- 用户现有食材：番茄、土豆  
- 整体用餐定位：快手晚餐  

## 2. **整套菜单概览表**  
| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|----------------|
| 快手家常炒蛋 | 15分钟   | 简单 | 200大卡        |

## 3. **分类采购清单**  
- 已有食材（无需额外购买）：番茄、土豆  
- 需要采购食材：鸡蛋、食用油、盐、葱花（根据具体做法可能需要）  

## 4. **单菜详细做法**  
- **快手家常炒蛋**  
  - **食材明细**：  
    - 鸡蛋 2个  
    - 番茄 1个  
    - 土豆 1个  
    - 食用油 适量  
    - 盐 适量  
    - 葱花 少许（可选）  
  - **分步烹饪步骤**：  
    1. 番茄洗净切块，土豆去皮切片。  
    2. 鸡蛋打入碗中，加少许盐搅拌均匀。  
    3. 热锅凉油，倒入鸡蛋液翻炒至凝固，盛出备用。  
    4. 锅中再加少量油，放入番茄和土豆翻炒至软。  
    5. 倒入炒好的鸡蛋，加入适量盐调味，翻炒均匀即可。  
    6. 出锅前撒上葱花增香。  
  - **烹饪小贴士**：  
    - 番茄和土豆可以提前切好，节省时间。  
    - 若喜欢口感更丰富，可加入少许生抽提鲜。  

## 5. **厨房操作先后建议**  
- 先处理食材：番茄切块、土豆切片、鸡蛋打散。  
- 热锅后先炒鸡蛋，再炒蔬菜，最后混合翻炒。  
- 整体流程简单，适合快速下厨。  

## 6. **整体营养小结**  
- 总热量：约200大卡  
- 饮食适配评价：符合低脂不辣的饮食需求，利用用户现有食材，搭配鸡蛋增加蛋白质摄入。  
- 微调建议：若需进一步减脂，可减少食用油用量或选择橄榄油替代。  

## 7. **饮食安全提醒**  
- 本菜单完全规避了用户忌口及过敏原，确保安全食用。
```

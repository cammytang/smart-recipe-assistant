# 菜品 1: 番茄炒土豆

### 菜品详细整理结果

#### 食材清单
- 土豆：2个
- 番茄：1个
- 青椒：少许
- 油：适量
- 盐：适量
- 味精：少许

#### 烹饪步骤
1. 备齐所需食材。用开水烫一下番茄，把皮撕掉，切碎，青椒切丝，土豆切丝后用水冲洗掉淀粉，备用。
2. 热锅放油烧至五成热时下番茄炒一下。
3. 加入土豆丝调中火，翻炒2-3分钟。
4. 然后放青椒丝在翻炒片刻。
5. 最后加入盐和味精调味即可。
6. 装盘上桌。

#### 总耗时
- 烹饪时间：约24分钟

#### 预估热量
- 约200-250大卡（根据具体用量调整）

#### 难度
- 初级

#### 烹饪小贴士
- 炒土豆丝要掌握好火候，以免会糊锅了。
- 如果喜欢更清淡的口感，可以减少油的使用量。
- 可以用其他蔬菜代替青椒，如胡萝卜或洋葱，增加口感层次。

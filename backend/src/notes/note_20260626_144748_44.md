# 用户需求：低脂不辣，现有食材 番茄 土豆， 两菜一汤

## 1. **用餐需求总览**
- **原始需求**：低脂不辣
- **忌口/过敏原**：暂无相关信息
- **用户冰箱现有食材**：番茄、土豆
- **整体用餐定位**：两菜一汤，快手晚餐

## 2. **整套菜单概览表**

| 菜名             | 制作时长 | 难度 | 单菜预估热量 |
|------------------|----------|------|--------------|
| 快手家常炒蛋     | 15分钟   | 简单 | 200大卡      |
| 番茄土豆炖汤     | 20分钟   | 简单 | 150大卡      |
| 土豆炒番茄       | 15分钟   | 简单 | 180大卡      |

## 3. **分类采购清单**

### 已有食材（无需额外购买）
- 番茄
- 土豆

### 需要采购食材
- 暂无需要采购的食材

## 4. **单菜详细做法**

### 快手家常炒蛋
- **食材明细**：
  - 鸡蛋 2个
  - 盐 适量
  - 食用油 1勺
- **分步烹饪步骤**：
  1. 将鸡蛋打入碗中，加入适量盐，搅拌均匀。
  2. 热锅凉油，倒入鸡蛋液，快速翻炒至凝固。
  3. 出锅装盘即可。
- **烹饪小贴士**：
  - 炒蛋时火候不宜过大，避免焦糊。

### 番茄土豆炖汤
- **食材明细**：
  - 番茄 1个
  - 土豆 1个
  - 清水 500ml
  - 盐 适量
- **分步烹饪步骤**：
  1. 番茄洗净切块，土豆去皮切块。
  2. 锅中加清水，放入番茄和土豆，大火煮开后转小火炖煮15分钟。
  3. 加入适量盐调味，搅拌均匀即可。
- **烹饪小贴士**：
  - 可根据口味加入少量香菜或葱花提味。

### 土豆炒番茄
- **食材明细**：
  - 土豆 1个
  - 番茄 1个
  - 盐 适量
  - 食用油 1勺
- **分步烹饪步骤**：
  1. 土豆去皮切片，番茄洗净切块。
  2. 热锅凉油，先将土豆片炒至微黄。
  3. 加入番茄块，继续翻炒至番茄出汁。
  4. 加入适量盐调味，翻炒均匀即可。
- **烹饪小贴士**：
  - 番茄炒制时间不宜过长，以免失去口感。

## 5. **厨房操作先后建议**
1. 先处理食材：将番茄和土豆清洗干净，切好备用。
2. 烧水准备炖汤：在锅中加入清水，开始炖煮番茄土豆汤。
3. 炒蛋：利用空闲时间炒蛋，确保炒蛋新鲜可口。
4. 炒土豆番茄：待汤炖煮约10分钟后，开始炒土豆番茄，保持火候适中。

## 6. **整体营养小结**
- **总热量**：约530大卡
- **饮食适配评价**：符合低脂不辣的饮食需求，食材简单易得，适合快手晚餐。
- **微调建议**：可根据个人口味添加少量香料或蔬菜提升风味。

## 7. **饮食安全提醒**
- 本套餐完全规避了用户提到的忌口和过敏原，确保安全食用。

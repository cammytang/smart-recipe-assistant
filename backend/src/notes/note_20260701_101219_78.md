# 研究报告：低脂不辣，现有食材 番茄 土豆,两菜一汤

```markdown
# 完整菜谱套餐：用户需求：低脂不辣，现有食材 番茄 土豆,两菜一汤

## 1. **用餐需求总览**  
   - 用户原始需求：低脂不辣，利用现有食材番茄和土豆制作两菜一汤。  
   - 忌口/过敏原：暂无相关信息。  
   - 用户冰箱现有食材：番茄、土豆。  
   - 整体用餐定位：低脂、家常、快手晚餐。

## 2. **整套菜单概览表**  
   | 菜名         | 制作时长 | 难度 | 单菜预估热量 |
   |--------------|----------|------|----------------|
   | 番茄炒土豆   | 20分钟   | 简单 | 150大卡        |
   | 清炒土豆丝   | 15分钟   | 简单 | 120大卡        |
   | 番茄蛋花汤   | 10分钟   | 简单 | 80大卡         |

## 3. **分类采购清单**  
   - 已有食材（无需额外购买）：番茄、土豆。  
   - 需要采购食材：鸡蛋（用于番茄蛋花汤）。  

## 4. **单菜详细做法**  
   ### 番茄炒土豆  
   - **食材明细**：  
     - 番茄 2个  
     - 土豆 1个  
     - 盐 适量  
     - 橄榄油 1勺  
   - **分步烹饪步骤**：  
     1. 土豆去皮切片，番茄洗净切块。  
     2. 热锅加橄榄油，放入土豆片翻炒至微黄。  
     3. 加入番茄块，继续翻炒至番茄出汁。  
     4. 加盐调味，炒匀后即可出锅。  
   - **烹饪小贴士**：  
     - 土豆片可提前用清水浸泡去除淀粉，口感更脆。  
     - 番茄炒制时间不宜过长，以免失去鲜味。

   ### 清炒土豆丝  
   - **食材明细**：  
     - 土豆 1个  
     - 盐 适量  
     - 橄榄油 1勺  
   - **分步烹饪步骤**：  
     1. 土豆去皮切丝，用清水冲洗干净，沥干水分。  
     2. 热锅加橄榄油，放入土豆丝快速翻炒。  
     3. 加盐调味，炒至土豆丝变软即可出锅。  
   - **烹饪小贴士**：  
     - 土豆丝尽量切得均匀，保证受热一致。  
     - 炒制时间控制在1-2分钟，避免过度炒制导致口感变老。

   ### 番茄蛋花汤  
   - **食材明细**：  
     - 番茄 1个  
     - 鸡蛋 1个  
     - 盐 适量  
     - 水 500ml  
   - **分步烹饪步骤**：  
     1. 番茄洗净切块，鸡蛋打散备用。  
     2. 锅中加水烧开，放入番茄块煮1分钟。  
     3. 慢慢倒入鸡蛋液，边倒边搅拌，形成蛋花。  
     4. 加盐调味，煮1分钟后即可关火。  
   - **烹饪小贴士**：  
     - 番茄煮的时间不宜过长，以保持其酸甜风味。  
     - 倒入鸡蛋液时要缓慢，确保蛋花细腻。

## 5. **厨房操作先后建议**  
   - 第一步：准备食材，将番茄和土豆清洗干净，土豆切片或丝，番茄切块。  
   - 第二步：先做番茄蛋花汤，因为需要等待水烧开，可以同时进行其他菜品的准备。  
   - 第三步：接着制作清炒土豆丝，耗时较短，适合在汤快好的时候进行。  
   - 第四步：最后炒番茄炒土豆，确保所有菜品新鲜上桌。

## 6. **整体营养小结**  
   - 总热量：约350大卡  
   - 饮食适配评价：符合低脂不辣的要求，主要使用番茄和土豆，搭配鸡蛋，营养均衡。  
   - 微调建议：若想增加蛋白质摄入，可加入少量豆腐或鸡胸肉。

## 7. **饮食安全提醒**  
   - 本套餐完全规避了用户忌口和过敏原（暂无相关信息），确保安全食用。
```

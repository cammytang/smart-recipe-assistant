# 菜品 3: 番茄蛋花汤

### 菜品详细整理结果

#### 食材清单
- 番茄：250g
- 鸡蛋：2颗
- 葱花：10g
- 盐：2g
- 酱油：10g
- 油：10g
- 金针菇：200g

#### 烹饪步骤
1. 热锅下油，加入番茄炒至软烂爆汁，汤底变红亮。
2. 倒入清水煮滚后转中火煮5分钟，让茄汁更浓香。
3. 加入金针菇再煮5分钟，让其吸满汤汁。
4. 鸡蛋打散，沿锅边慢慢倒入，等微凝固后轻轻搅成滑蛋花。
5. 最后加入盐和酱油调味，拌匀。
6. 撒上葱花即可食用。

#### 总耗时
约15分钟

#### 预估热量
约120大卡（每份）

#### 难度
简单

#### 烹饪小贴士
1. 番茄炒制时要炒至软烂，这样汤汁更浓郁。
2. 蛋液倒入时要缓慢，避免蛋花过老。
3. 可根据个人口味调整盐和酱油的用量。

# 研究报告：低脂不辣，现有食材 番茄 土豆

```markdown
<REPORT_TEMPLATE>
1. **用餐需求总览**  
   - 用户原始需求：低脂不辣  
   - 忌口/过敏原：暂无相关信息  
   - 用户冰箱现有食材：番茄、土豆  
   - 整体用餐定位：低脂清淡，适合一人食或家庭餐  

2. **整套菜单概览表**  
| 菜名         | 制作时长 | 难度 | 单菜预估热量 |
|--------------|----------|------|----------------|
| 番茄土豆汤   | 30分钟   | 简单 | 150大卡        |
| 炒番茄土豆片 | 20分钟   | 简单 | 180大卡        |

3. **分类采购清单**  
- 已有食材（无需额外购买）：番茄、土豆  
- 需要采购食材：暂无需要额外采购的食材  

4. **单菜详细做法**  
### 番茄土豆汤  
- **食材明细**：  
  - 番茄 2个  
  - 土豆 1个  
  - 洋葱 1/4个（可选）  
  - 盐 少许  
  - 黑胡椒 少许  
  - 水 500ml  

- **分步烹饪步骤**：  
  1. 番茄洗净切块，土豆去皮切块。  
  2. 锅中加水煮沸，放入番茄和土豆块，煮至软烂。  
  3. 加入盐和黑胡椒调味，搅拌均匀即可。  

- **烹饪小贴士**：  
  - 可加入少量洋葱提升风味。  
  - 若喜欢更浓郁口感，可加入少许牛奶或淡奶油。  

### 炒番茄土豆片  
- **食材明细**：  
  - 番茄 1个  
  - 土豆 1个  
  - 盐 少许  
  - 黑胡椒 少许  
  - 食用油 1勺  

- **分步烹饪步骤**：  
  1. 番茄洗净切片，土豆去皮切片。  
  2. 热锅加食用油，放入土豆片翻炒至微黄。  
  3. 加入番茄片继续翻炒，直至番茄出汁。  
  4. 加入盐和黑胡椒调味，翻炒均匀即可。  

- **烹饪小贴士**：  
  - 番茄和土豆切片尽量薄一些，更容易熟透。  
  - 若喜欢酸甜口味，可适量加入少许糖。  

5. **厨房操作先后建议**  
- 先准备番茄土豆汤：先将番茄和土豆处理好，煮汤。  
- 在汤煮的过程中，可以同时准备炒番茄土豆片的食材。  
- 最后进行炒制，确保两道菜同时完成。  

6. **整体营养小结**  
- 总热量：约330大卡  
- 饮食适配评价：符合低脂不辣要求，合理利用了用户现有的番茄和土豆，营养均衡。  
- 微调建议：若希望增加蛋白质，可添加少量鸡胸肉或豆腐。  

7. **饮食安全提醒**  
- 本套餐完全规避了用户忌口和过敏原，确保安全健康。
```

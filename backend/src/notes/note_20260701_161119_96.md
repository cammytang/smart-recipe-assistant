## 4. **单菜详细做法**

### 番茄炒土豆

#### 食材明细
- 番茄 2个
- 土豆 1个
- 盐 适量
- 食用油 适量

#### 分步烹饪步骤
1. 将番茄洗净切块，土豆去皮切片。
2. 热锅凉油，放入土豆片翻炒至微黄。
3. 加入番茄块继续翻炒，炒至番茄出汁。
4. 根据口味加入适量盐调味，翻炒均匀即可出锅。

#### 烹饪小贴士
- 土豆片可提前用清水浸泡，避免氧化变色。
- 番茄炒制时间不宜过长，以保持口感和营养。
